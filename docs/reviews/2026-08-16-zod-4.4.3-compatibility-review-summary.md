# Zod 4.4.3 Upgrade Compatibility Summary

Date: August 16, 2026
Status: Passed; compatibility evidence only

## Outcome

The repository now pins Zod **4.4.3**, upgraded from 4.3.6. The existing
schemas, normalizers, generator, and other validator packages were unchanged.

Zod 4.4.3 passed every evaluated compatibility gate:

| Gate | Result |
| --- | --- |
| TypeScript typecheck | Pass |
| Full Bun suite after compiled-artifact regeneration | **109 passed, 0 failed** |
| Assertions | 1,193 |
| Native-transform compiled Zod | All discovered schemas optimized |
| Compiled Zod with manual normalization | 2/2 schemas, 100% coverage, fast-path eligible, no fallbacks |
| Readable compiler-review example | 1/1 schema and all declared cases passed |
| Fully bundled artifact | Built; known runtime incompatibility still detected |

No schema, normalizer, expected output, or normalized issue needed to change.

"Compiled Zod" means code generated by `zod-compiler` from the pinned Zod
schemas; it is not a separate validation library version.

## Compiler results

The measured external-package native-transform build optimized nine intended
exports, with the compiler reporting 11/11 when two hoisted inline schemas are
included. Its artifact was 99,291 bytes.

The transform-free manual-normalizer build compiled both request schemas. Each
had 48/48 compilable nodes, 100% coverage, fast-path eligibility, and zero
fallbacks. Its artifact was 71,368 bytes.

The fully bundled artifact remains runtime-incompatible under Bun 1.3.14. This
does not affect the external-package build used by the benchmark, and the gate
continues to prevent silent fallback to interpreted Zod.

## Scope limit

This compatibility check was not itself a performance run. Test durations and
generated artifact sizes do not establish validation speed or runtime memory
behavior. A separate fresh-process Zod 4.4.3 benchmark was completed afterward
and is documented independently.

The upgrade added no inputs and did not modify the deterministic synthetic
generator or vocabulary.
