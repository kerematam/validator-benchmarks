# Zod 4.4.3 Upgrade Compatibility Review

Date: August 16, 2026
Status: Compatibility gates passed; no performance conclusion

## Executive summary

The benchmark repository was upgraded from Zod 4.3.6 to the exact pinned
version Zod 4.4.3. The compiler, schemas, normalizers, synthetic inputs, and
other validator dependencies were not changed as part of the upgrade.

Zod 4.4.3 passed the complete behavioral suite after the compiled artifacts
were regenerated:

- TypeScript typecheck: pass;
- Bun test suite: **109 passed, 0 failed, 1,193 assertions**;
- native-transform compiled Zod: all discovered schemas optimized;
- transform-free compiled Zod: both schemas retained 100% compiler coverage,
  no fallbacks, and fast-path eligibility; and
- readable compiler-review example: all generated validators passed their
  declared cases.

The separately labeled fully bundled compiled-Zod artifact still built but
remained runtime-incompatible under Bun 1.3.14. That is the previously recorded
compatibility classification, not a new failure in the measured
external-package build.

This review establishes compatibility only. It does not compare Zod 4.4.3
performance with Zod 4.3.6. The August 16 diagnostic benchmark remains a Zod
4.3.6 result and must not be relabeled.

## Review boundary

The evaluation covered compatibility of the existing benchmark code with the
new Zod version. It did not change:

- contract schemas or normalization rules;
- compiler version or build configuration;
- synthetic generator vocabulary, profiles, or seeds;
- Ajv, TypeBox, or Valibot implementations; or
- benchmark timing or memory methodology.

No performance command was run. Test durations are not benchmark results and
must not be used to infer a Zod 4.3.6-to-4.4.3 speed change.

bun run typecheck

bun run build:compiler-review

The final test invocation occurred after all compiled artifacts were rebuilt,
so the reported parity result covers the freshly generated Zod 4.4.3 outputs.

## Compiled-Zod results

### Native-transform schemas

The external-package compiled build discovered nine exported schemas plus two
hoisted inline schemas. The compiler reported **11 of 11** optimized schemas
across the source file and the build gate reported nine intended exported
schemas optimized.

| Property | Result |
| --- | --- |

| Package mode | External |
| Intended exported schemas | 9 optimized |
| Compiler summary | 11/11 including hoisted schemas |
| Artifact size | 99,291 bytes |

The external-package artifact is the compiled-Zod path used by the benchmark.

### Transform-free schemas with manual normalization

Both request schemas compiled successfully.

| Schema | Compilable nodes | Coverage | Fast path | Fallbacks |
| --- | ---: | ---: | --- | ---: |
| Diagnostic request | 48/48 | 100% | Eligible | 0 |
| Standard request | 48/48 | 100% | Eligible | 0 |

The generated artifact was 71,368 bytes. The result preserves the intended
reference architecture: compiled structural Zod validation followed by the
shared manual normalizer.

### Readable compiler-review example

The small review-only schema compiled **1 of 1** discovered Zod schemas. Its
valid case and five invalid cases produced their expected verdicts. The same
example also regenerated its Ajv and TypeBox reference validators.

This example is for inspecting generated validator code. It is not a benchmark
and contributes no performance evidence.

## Privacy and data boundary

The upgrade introduced no test inputs and made no change to the deterministic
synthetic generator or its explicit artificial vocabulary. The compatibility
suite continued to exercise the generated-value vocabulary tests and complete
synthetic diagnostic profile.

This review contains package versions, safe aggregate counts, compiler
diagnostics, and generated artifact sizes only. It does not contain raw request
values, private fixtures, machine hostnames, or unrelated repository details.

## Interpretation

The evidence supports these conclusions:

- existing Zod behavior is compatible with Zod 4.4.3 for the declared test
  corpus;
- `zod-compiler` 1.23.6 can still compile both measured Zod architectures;
- the transform-free schemas retain full coverage and fast-path eligibility;
- the known bundled-output incompatibility remains correctly detected; and
- no schema, normalizer, or parity-test change was needed for the upgrade.

The evidence does not support:

- a claim that Zod 4.4.3 is faster or uses less memory than Zod 4.3.6;
- reuse of the Zod 4.3.6 benchmark numbers as Zod 4.4.3 results;
- conclusions about versions newer than the pinned dependencies; or
- changing the bundled-artifact compatibility classification.
